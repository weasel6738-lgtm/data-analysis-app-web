# FabriQ visual system

FabriQ는 밝은 조명의 생산기술 상황실에서 반복적으로 사용하는 operate-first
워크벤치다. 장식적 AI 대시보드가 아니라, 공정 신호가 판단과 검증으로 이어지는
한 장의 디지털 관리도다.

## World

- **Palette:** warm-white data paper, cool gray factory canvas, oxide blue
  navigation and analytical marks, amber for attention, red only for real risk.
- **Type:** Korean-first SUIT workhorse stack. Monospace is restricted to
  measurements, dates and machine status.
- **Geometry:** 1px rules, 2–3px radii, dense tables and a single broad SPC trace.
  Shadows have a downward offset and only separate working sheets from canvas.
- **Hierarchy:** evidence first, ranked candidates second, workflow handoff third.
  No decorative KPI-card grid or neon technical costume.

## Behavior

The fixed desktop rail makes all five workflows directly reachable. Upload is
always visible; drag/drop turns the current control sheet into the target.
Loading, fallback, validation and synthetic-data states are explicit. Below
1050px the rail contracts and the workflow stacks; below 720px it becomes a
horizontal task strip and measurements remain legible without horizontal page
scrolling. Focus treatment, semantic status copy and reduced-motion support are
required.
